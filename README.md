# calculadora-imc

🍎 Você Saudável - Calculadora de IMC

Este projeto é uma aplicação web simples e intuitiva projetada para ajudar usuários a calcularem seu Índice de Massa Corporal (IMC) de forma rápida. O foco principal foi criar uma interface amigável (UI) e garantir uma experiência de usuário (UX) fluida.

🛠️ Tecnologias Utilizadas

HTML: Estruturação semântica do conteúdo.

CSS: Estilização moderna, utilizando técnicas de layout para garantir o alinhamento dos elementos e responsividade.

JavaScript: Lógica de programação para capturar os dados de entrada, realizar o cálculo matemático e exibir o resultado dinamicamente na tela.

✨ Funcionalidades

Cálculo em tempo real com base no peso e altura informados;

Classificação automática do resultado (Ex: Normal, Sobrepeso, etc.);

Design visual focado em bem-estar e saúde.
